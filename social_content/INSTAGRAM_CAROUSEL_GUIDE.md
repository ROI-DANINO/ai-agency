## מדריך אובייקטים לפי נושא

| נושא | אובייקט מומלץ | למה |
|---|---|---|
| כיוון / ניווט / החלטה | מצפן | מסע, גילוי, כיוון |
| לימוד מהטלפון / נגישות | טלפון על מפה / שולחן | אמיתי, יומיומי |
| מסע / תהליך / שלבים | מפה טופוגרפית | Adventure aesthetic |
| הערות / שיטה / למידה | sticky note, מחברת | מוכר, לא מאיים |
| מילואים / רקע | ציוד שטח (בעדינות) | ישראלי, אמיתי |
| פתיחת הזדמנויות | מפתח ישן + מצפן | "דלתות שנפתחו" |
| AI / כלים | שום רובוט! — כלי יד, מקלדת | אנושי, לא sci-fi |

**אובייקט חתימה:** מצפן — מופיע בכל פוסט כ-visual signature.

## כללי Hook (שקף 1)

**3 פורמטים שעובדים:**

1. **ניגוד/סתירה:** "למדתי לבחינות / מהטלפון. / במילואים."
2. **מספר ספציפי:** "ממוצע 95. בלי לפטופ. בלי ספרים."
3. **עובדה בלתי צפויה:** "עזבתי פסיכולוגיה. לא כי נכשלתי."

**כלל:** Hook = 3 שורות מקסימום. כל שורה = מחשבה אחת.
